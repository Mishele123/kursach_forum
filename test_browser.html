📍 Available Endpoints

👤 Authentication & Profile (US1, US2)

POST /auth/register

Đăng ký tài khoản mới

POST /auth/login

Đăng nhập vào hệ thống

GET /auth/me

Xem thông tin profile của mình

PUT /auth/me

Cập nhật profile (city, discipline, interests, bio)

📝 Posts (US3, US4)

POST /posts

Tạo bài viết mới (ride report, tip, event)

GET /posts

Lấy danh sách bài viết (có phân trang: limit, offset)

GET /posts/{id}

Xem chi tiết một bài viết

🚲 Bikes (US5)

POST /bikes

Thêm xe đạp mới

GET /bikes/my-bikes

Xem danh sách xe đạp của mình

💡 Hướng dẫn sử dụng

  1. Click vào "Mở Swagger UI" để mở giao diện test API
  2. Trong Swagger UI, bạn có thể:
    • Xem tất cả các endpoints
    • Xem request/response schema
    • Click "Try it out" để test API trực tiếp
    • Nhập dữ liệu và click "Execute"
  3. Thử tạo user mới với POST /auth/register
  4. Thử tạo bài viết với POST /posts
  5. Thử thêm xe đạp với POST /bikes
